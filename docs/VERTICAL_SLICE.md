# ASHFALL — Vertical Slice Target

The slice is the FIRST GAME. Everything afterwards expands it.

## Contents

- One player character
- A small overworld of several chunks
- Simple terrain
- Exploration
- One or more simple NPCs
- One small outpost
- One creature
- Basic combat
- Loot
- Inventory
- Equipment
- A small dungeon
- Save / load

## Loop

EXPLORE -> DISCOVER -> ENCOUNTER DANGER -> FIGHT OR ESCAPE -> LOOT -> RETURN ->
EQUIP / TRADE -> EXPLORE FARTHER

## Success test

The slice is NOT complete merely because it runs. Can the player:

1. Start?
2. Move?
3. Explore?
4. Discover something?
5. Encounter danger?
6. Make a meaningful decision?
7. Fight or escape?
8. Receive a reward?
9. Improve?
10. Save?
11. Load?
12. Continue exploring?

If any answer is no, keep fixing the slice. Do not advance to Phase 4.

## The real question

Is "ONE CHARACTER + SMALL WORLD + EXPLORATION + DANGER + REWARD" fun?

If it is not, the answer is never "add more simulation".
